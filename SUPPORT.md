# Support & Community

Thank you for using the **Self-Healing Pipeline System Configuration** project! Here is how to get help, ask questions, or connect with the community.

## Documentation & Guides

- **Getting Started**: Check out the [README.md](README.md) for local and Docker quickstart instructions.

### GitHub Issues
- **Bug Reports**: If you found a bug or unexpected behavior, please [open a bug report](https://github.com/laasyaarun18-gif/Pipeline-System/issues/new?template=bug_report.yml).
- **Feature Requests**: Have an idea for a new self-healing rule, cloud connector, or dashboard visualization? [Open a feature request](https://github.com/laasyaarun18-gif/Pipeline-System/issues/new?template=feature_request.yml).
